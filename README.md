# green-vs-red-
very simple green vs red with models made by me



# linux install commands 
1. downloading it
```lua
wget https://github.com/ryderguy/green-vs-red-/releases/download/1.0/GreenvsRed-linux.zip
```
2. extracting it
```lua
unzip ~/Downloads/GreenvsRed-linux.zip
```
3. cd into it
```lua
cd ~/Downloads/Green vs Red
```
4. run it (also can just click on the app image)
```lua
 ./'Green vs Red.sh'
```
